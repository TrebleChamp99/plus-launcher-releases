# Plus Launcher — releases

Installers for **Plus Launcher**, a fullscreen, controller-first game launcher for Windows.

- **New install:** open the latest release below and run `Plus Launcher_x.y.z_x64-setup.exe`.
- **Already installed?** It updates itself: Settings › About, or the quick menu.

The app's code lives in a private repository; this one only holds the signed installers and `latest.json`, which the app reads to find updates.
